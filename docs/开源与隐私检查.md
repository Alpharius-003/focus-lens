# Web 0.1.0 开源、隐私与 Pages 检查

检查日期：2026-11-17。范围仅为 focus_lens_web 的当前源码与静态构建，不涉及父目录桌面软件，不修改 Mac / Windows 发行包。本次未创建提交、推送仓库或公开部署。

## 结论

demofile-net 的上游为 MIT。现有许可允许在保留版权和许可的前提下使用、修改、分发并加入自己的署名/社区联系方式。React、PixiJS、ECharts、sql.js 以及解析器运行依赖采用 MIT、Apache-2.0、BSD-3-Clause、ISC、0BSD 等条款，当前未发现要求整个项目改用 GPL 或禁止公开源码的组件。组件的确切许可仍以保留的原始文本为准，不能把所有组件统称为 MIT。

代码许可的已发现缺漏已补齐；游戏素材的再分发授权尚不能据此认定完成。网站图片和应用图标来自 Valve；社区 API、源码托管、来源标注及项目 MIT 均不自动授予图片权利。正式公开前需确认 Valve 对该类非官方工具分发素材的适用授权，或换成获得授权的素材。这不是认定该项目侵权，而是现有材料不足以确认授权。

## 已处理问题

1. 根 LICENSE 原来只标了解析器作者。现改为项目作者 EchoSkn1 与 demofile-net 部分的 Saul Rennison 分别署名，保留上游完整许可、ACKNOWLEDGEMENTS 和相关版权。
2. 删除 Web 第三方说明中混入的 Electron、Steam 等桌面依赖描述；补齐 21 个 npm 运行组件的完整许可、ECharts NOTICE、NuGet 运行依赖及 .NET 完整许可与第三方声明。npm run build 自动刷新并附带全部许可。
3. 增加网页可访问的“许可与隐私说明”，说明第三方归属、游戏素材权利、浏览器存储以及托管平台仍会收到网页访问连接信息。
4. 原本浏览器解析程序集带有本机用户名/目录的 PDB 路径。重新构建时关闭调试符号并映射构建路径，重新扫描发布源码及产物未再匹配本机用户路径。
5. reports/ 中真实对局昵称截图、原始测试工程、日志与本机验收资料原先未完整忽略。现整体排除于 Git 和干净源码包；本地文件保留。SDK、依赖、录像、数据库、凭据、构建目录也被排除。没有删除用户录像或已有研究资料。
6. 添加公开文件模式扫描、干净源码打包脚本和 Pages 工作流，仅发布 dist，避免公开整个开发目录。

## 发布方式

使用 release 内的干净源码包，不上传原始开发目录或父目录。在仓库 Settings → Pages 中选择 GitHub Actions；首次上传及 noreply 邮箱设置见 [GitHub Pages 发布指南](GitHub-Pages发布指南.md)。不要强推或提交个人凭据。
