# 云服务器部署

1. 将发布包解压到站点目录，例如 `/var/www/focus-lens`，确认该目录直接包含 `index.html`、`assets/`、`parser/`、`focus-lens.png`。
2. 接入已有 HTTPS 域名，使用同目录 `nginx.conf` 的 MIME、响应头和静态路由配置。示例是 HTTP 静态配置骨架，需要结合自己的 TLS 配置，不要把公开 HTTP 当成最终部署。
3. 开启 gzip / Brotli 可减少 WASM 首次下载流量。只允许静态 GET / HEAD 即可，无需 .NET / Node / 数据库 / Steam 服务常驻。
4. 在 Chrome / Edge 打开域名，导入本地 demo；开发者工具 Network 不应出现录像 POST / PUT 或外部服务请求。下载进度里的运行时指网页程序资源，非录像上传。
5. 验证解析、地图、笔记、刷新恢复、工程导出与重新导入。个人浏览器数据不会出现在服务器目录。

网站地址变更或清理浏览器网站数据会影响本地档案；升级前建议用户导出重要工程。录像与工程无需发送给服务器。
